UX REFACTOR: Streamline Menu & Stock Architecture into a Unified, High-Density Retail Tool

Refactor the Menu & Inventory management interface from the fragmented 3-tab layout into a unified, high-efficiency retail workspace. Retain standard commercial retail terminology—do not use patronizing or oversimplified language—while eliminating bureaucratic form-hopping.

1. Unified Single-Screen Layout (Eliminate the 3-Tab Ping-Pong):
- Remove the separate top tabs ("Categories", "Menu Items", "Shelf Loading").
- Merge catalog management into a single, cohesive view:
  - Category Navigation Bar: A horizontal ribbon or left sidebar showing existing categories ([Cakes], [Pastries], etc.) with category management actions (Reorder, Edit, "+ Add Category").
  - Active Catalog Grid: Selecting a category immediately renders its assigned items as compact, high-density cards in the main workspace.
  - Inline Action: Include a prominent "+ Add Item" card or button directly inside the active category grid so staff never leave the view.

2. Professional Retail Terminology:
- Use clean, standard retail terms:
  - "Pricing Type": Segmented control for [ Per Piece ] vs [ By Weight / Pound ].
  - "Item Status": Toggle for [ Active / Inactive ].
  - "Track Inventory": Clean toggle with input for "Current Stock".
  - "Restock": Quick action to increment shelf inventory.

3. Standard Cake Weight Presets:
- In the item creator modal, when [ By Weight / Pound ] is selected:
  - Do NOT require staff to manually configure weight labels from scratch.
  - Provide pre-configured size chips: [ 0.5 lb ], [ 1 lb ], [ 2 lb ], [ 3 lb ], and [ Custom ].
  - Clicking any chip enables that tier and opens clean inputs for Price (NPR) and Initial Stock.

4. Inline Restocking on Item Cards:
- On every item card in the management grid, display current stock alongside a compact "Restock" control.
- Allow staff to tap quick increment chips (+1, +5, +10) or type an amount directly on the card to update live shelf stock in Firebase without opening sub-menus.

5. High-Density Visual Architecture:
- Eliminate massive empty black containers. Use compact, tight cards with the established Firebase flame gradient borders and glowing accents.
- Ensure modals are compact, centered, and mobile-responsive with clear [ Cancel ] and [ Save Changes ] actions.
