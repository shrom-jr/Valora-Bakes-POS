SYSTEM NAVIGATION & DASHBOARD REFACTOR: Split Register Terminal and Back-Office Dashboard with Sidebar Layout

Refactor the application layout and routing so the cashier register remains completely clean, and all administrative tools (Overview, Menu, Inventory) live inside a dedicated Dashboard workspace with vertical sidebar navigation, matching professional POS architecture:

1. Top Command Bar Cleanup:
- Remove clutter from the top bar. It should only display:
  - Left: Store Icon + "Bakery POS".
  - Right:
    - Primary Navigation Switch: 
      - When on the Cashier Register (/register): Show an incandescent flame button "[ ⚡ Dashboard ]".
      - When anywhere inside the Dashboard (/dashboard/*): Show an incandescent flame button "[ 🛒 Counter Register ]" to return to billing.
    - Status & Session: Emerald pulse online dot + Staff session pill + Sign-out trigger.

2. Back-Office Dashboard Shell (/dashboard/*):
Create a responsive management shell featuring a dedicated left sidebar rail and a main content viewport:
- Left Sidebar Rail (Dark Obsidian #0E0F12 with ember right border):
  - Sidebar Header: "MANAGEMENT PORTAL" in crisp, subtle uppercase tracking.
  - Navigation Items (Vertical stack with tactile hover and active flame-accent glow):
    1. "Overview" (icon: LayoutDashboard) -> /dashboard (default view)
    2. "Menu & Prices" (icon: UtensilsCrossed or Tag) -> /dashboard/menu
    3. "Shelf Inventory" (icon: PackageSearch or Boxes) -> /dashboard/inventory
  - Active tab styling: Glowing amber/flame background highlight with solid white text.
- Mobile Behavior: Collapses into a sleek bottom sheet or hamburger slide-out menu with 48px touch targets.

3. The Three Dashboard Views:

View A: "Overview" (/dashboard)
- Top KPI Summary Cards (4 Columns):
  1. "Today's Sales": Gross NPR revenue and count of settled bills.
  2. "Cash Inflow": NPR collected in physical cash.
  3. "Digital / QR Inflow": NPR collected digitally.
  4. "Stock Alerts": Count of items sold out or below low-stock threshold.
- Lower Grid:
  - Left Panel: "Today's Settlement Details" (Average ticket size, cash/QR percentage breakdown).
  - Right Panel: "Top Selling Bakes" (Ranked list of best-selling items today with quantities and revenue).
- Live Firebase binding with clean empty zero states when no transactions have occurred today.

View B: "Menu & Prices" (/dashboard/menu)
- Pure catalog and pricing management without restock clutter:
  - Horizontal Category ribbon with "+ Add Category" button.
  - Product Grid showing Item Name, Category, Pricing Mode (Per Piece vs. By Weight/Pound), Base/Tier NPR Prices, and Edit ("...") trigger.
  - Prominent "+ Add Menu Item" flame power-button opening the item creator modal (with 0.5 lb, 1 lb, 2 lb presets for cakes).

View C: "Shelf Inventory" (/dashboard/inventory)
- Fast-action morning bake and shelf stock control:
  - Category filter pills.
  - High-density list/grid of every sellable product and cake weight tier.
  - Live stock status pill (Emerald = In Stock, Amber = Low Stock, Red = Sold Out).
  - Rapid Morning Bake Controls: Direct [+1] [+5] [+10] one-tap increment chips and custom numeric entry to update shelf counts atomically in Firebase.

4. Aesthetic Standards:
Strictly preserve the approved Firebase Console theme: deep obsidian background (#0E0F12, #14161B), razor-sharp solid white headings, bright off-white labels (#E2E8F0), tabular monospaced numbers for all NPR amounts and timestamps, and radiant gold-to-coral flame gradients on primary active elements.
