PHASE 5 IMPLEMENTATION: Sales Reports, Store Settings, Customer Credit Readiness, and Thermal Receipt Engine

Implement Phase 5 for the Bakery POS application. Add date-filtered sales reporting, store profile settings with tax compliance, a dormant customer credit toggle, and an 80mm/58mm thermal receipt printing engine:

1. Navigation & Route Architecture:
Update the dashboard sidebar rail to include two new navigation links:
- "Reports" (icon: BarChart3 or TrendingUp) -> /dashboard/reports
- "Settings" (icon: Settings) -> /dashboard/settings
Preserve active flame-accent highlights, smooth scrolling, and mobile responsiveness.

2. Date-Filtered Reporting Engine (/dashboard/reports):
- Date Range Selector (Pills): [ Today ], [ Yesterday ], [ This Week ], [ This Month ].
- Summary Performance Strip (5 KPI Cards):
  1. "Total Revenue": Gross NPR for selected timeframe.
  2. "Settled Bills": Count of completed orders.
  3. "Average Ticket": NPR average spend per customer.
  4. "Total Outflow": Total shop expenses recorded in period.
  5. "Net Margin": Revenue minus Outflow with status coloring.
- Performance Breakdown (2 Panels):
  - Left Panel: "Top 5 Best Sellers" (Ranked by quantity sold and total revenue contribution).
  - Right Panel: "Slow-Moving Inventory" (Items with zero or lowest sales in the period to identify waste/spoilage risks).
- Firebase Querying: Aggregate efficiently from `/dailySummaries` and `/sales` without freezing the UI.

3. Store Profile, Tax & Security Settings (/dashboard/settings):
- Business Profile Card:
  - Bakery Name (e.g., "Valora Bakes")
  - Branch / Address (e.g., "Pepsicola, Kathmandu")
  - Contact Phone Number
  - PAN / VAT Registration Number (printed on tax receipts)
  - Receipt Greeting & Footer (e.g., "Fresh Bakes Everyday • Thank you for your visit!")
  - Store data persisted under `/settings/profile` in Firebase RTDB.
- Feature Toggles Card:
  - "Customer Credit / Udharo System": Master toggle switch (Default: OFF).
  - Stored under `/settings/features/customerCredit`. When OFF, counter register strictly processes Cash and QR.
- Security & Password Card:
  - Direct password update input for the logged-in staff/admin user via Firebase Auth.

4. Dual-Format Thermal Receipt Engine (80mm & 58mm):
- Thermal Print Config:
  - Provide a toggle in Settings: [ 80mm Standard Roll ] vs [ 58mm Handheld Roll ].
- Receipt Anatomy:
  - Centered Header: Store Name, Branch Address, Phone, PAN/VAT Number.
  - Metadata: Bill #[number], Date, Time, Cashier Name.
  - Itemized Table: Monospace columns with tabular alignment:
    - 80mm: Qty (3ch) | Item & Weight (20ch) | Rate (8ch) | Total (9ch) — 72mm printable boundary.
    - 58mm: Qty (2ch) | Item (12ch) | Total (8ch) — 48mm printable boundary.
  - Totals: Subtotal, Discount (if applied), Grand Total NPR, Tender Type (Cash + Tendered/Change, or QR Standee).
  - Footer: Custom greeting + "Software by Valora POS".
- Strict Print Styling (@media print):
  - Remove all browser headers, footers, margins, sidebar, topbar, and screen backgrounds.
  - Pure black-and-white high-contrast typography optimized for thermal transfer heads.

5. Checkout Integration on Register (/register):
- When a sale completes, the checkout modal renders the receipt preview with two immediate cashier actions:
  - [ 🖨️ Print Receipt ]: Triggers window.print().
  - [ ⚡ Done / Next Order ]: Closes the modal, clears the register, and focuses the grid for the next customer.
